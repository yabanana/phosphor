# Agent skills (vendored)

The skill folders here (except any Phosphor-specific ones added later) are
copied unmodified from [mattpocock/skills](https://github.com/mattpocock/skills)
at commit 5863806 (2026-11-12), MIT licensed (`MATTPOCOCK-LICENSE`). They
drive the F15 planning and delivery flow: `/grill-with-docs` or `/grill-me`
to align, `/wayfinder` (with `research` and `prototype`) for decisions that
need investigation, `/to-spec` and `/to-tickets` for the plan, `/implement`
(`tdd`, `code-review`) to build. `/setup-matt-pocock-skills` configures the
tracker and domain docs once per repo.

Update by re-copying the same folders from a newer upstream commit and
recording it here.
