# 01: KHR material extensions — status, parameters, BSDF and layering

Type: research
Status: resolved
Blocked by: none

## Question

For each glTF material extension relevant to F15.1 (clearcoat, sheen,
anisotropy, transmission, volume, ior, specular, iridescence,
diffuse_transmission, volume_scatter or any subsurface proposal,
emissive_strength, dispersion) and KHR_texture_transform: ratification status
today, parameters with units/defaults/ranges/texture channels, the exact BSDF
formulas the Khronos specification defines (glTF 2.0 Appendix B and each
extension README), the layering/energy-combination order between them, and
how the Khronos glTF Sample Viewer implements each (LUTs, approximations).
Also: how tinygltf exposes unknown extensions.
Findings: `.scratch/f15/research/khr-materials.md`.

## Answer

Findings: [khr-materials.md](../research/khr-materials.md) (KhronosGroup/glTF
`f93f8af`, Sample-Renderer `cc3d5ff`, Sample-Viewer `7306f9c`, tinygltf
`v2.9.7`/`488a70a`).

- Ratified: clearcoat, sheen, anisotropy, transmission, volume, ior, specular,
  iridescence, emissive_strength, dispersion, texture_transform.
  Release candidate: diffuse_transmission. Draft: KHR_materials_scatter
  (PR #2579, replaces volume_scatter #2453 and diffuse_transmission; mirrors
  OpenPBR), plus coat/fuzz/diffuse_roughness drafts that may replace
  clearcoat/sheen.
- Layering (top to bottom): clearcoat > sheen > base (`mix(dielectric, metal,
  metallic)`); inside the dielectric: ior/specular/iridescence Fresnel, then
  `mix(diffuse_bsdf, specular_btdf·baseColor, transmission)` with diffuse
  transmission inside `diffuse_bsdf`; emission under the coat, scaled by
  `1 − clearcoat·F_coat`. Specular/iridescence weight the base by
  `1 − weight·max(F)`; sheen scales the base by its E(μ) albedo table.
- Decisions:
  - F15.1 feature set = the six roadmap lobes as ratified extensions
    (clearcoat, sheen, anisotropy, transmission + volume, iridescence) plus the
    companions they depend on (ior, specular), emissive_strength (folded into
    the emissive factor at load) and KHR_texture_transform (ticket 02);
    subsurface per ticket 10. Dispersion is ratified but outside the roadmap
    list: reported unsupported, candidate for F16.2 glass.
  - Phosphor follows the ratified text where the Sample Renderer deviates:
    clearcoat F0 fixed at IOR 1.5, `(1 − weight·max(F))` base weighting,
    iridescence evaluated per light sample at V·H (environment/albedo terms at
    N·V). Deviations from the Sample Renderer are listed in the reference
    report so side-by-side differences are explained, not tuned away.
  - Multiple-scattering compensation is not part of the spec: not added; the
    furnace test records the single-scattering energy loss.
  - The sheen E(μ, roughness) table is generated by a Phosphor tool from the
    Charlie distribution (like `tools/dfg_table.py`), with a negative control;
    the pre-baked Sample Renderer PNG is not imported.
  - tinygltf stays at v2.9.7; a portable parser converts the `Value` trees
    (including texture refs and nested texture_transform) into the material
    description, unit-tested with small glTF JSON fixtures.
  - The material description models lobes, not extension JSON, so future
    coat/fuzz extensions map onto the same features.

> Superseded in part by [ADR-0007](../../../docs/adr/0007-specular-multiple-scattering-compensation.md) (2026-11-15): Appendix B has no
> multiple-scattering lobe; the engine now applies the Kulla-Conty compensation by default (`--specular-ms off` = the Appendix B lobe).
